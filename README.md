# Mitch — Boundary-Set Platonic AI Companion

A boundary-set platonic AI companion web app designed to encourage healthy conversational habits and mindful screen time. Built with Next.js, React, Tailwind CSS, and the Google Gemini API, featuring persistent platonic role guardrails, live session timers, and 15-minute reflection break nudges.

## Tech Stack
* Next.js / React / TypeScript
* Tailwind CSS
* Google Gemini API
* Vercel

## Run Locally
```bash
git clone [https://github.com/chawsandyhtet-kuro/mitch-ai-companion.git](https://github.com/chawsandyhtet-kuro/mitch-ai-companion.git)
cd mitch-ai-companion
npm install
npm run dev
